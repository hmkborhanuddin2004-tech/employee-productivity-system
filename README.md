# 📊 Employee Productivity & Performance Analytics System

A comprehensive enterprise productivity monitoring, workflow tracking, and operational analytics web application built with **Next.js**, **TypeScript**, and **Tailwind CSS**. Provides leadership and HR teams with transparent activity tracking, automated timesheets, and performance visualization.

---

## 🌟 Key Features

- 📈 **Real-Time Productivity Dashboard:** High-level metrics showing team output, active hours, focus scores, and project delivery status.
- ⏱️ **Automated Timesheets & Activity Logging:** Categorized task tracking with automated idle detection and project milestone mapping.
- 🌐 **Bilingual Interface:** Full support for both English and Bengali (বাংলা) localization for local enterprise workplaces.
- 🛡️ **Privacy-First Architecture:** Role-based access control (RBAC) ensuring employee privacy and secure administrative oversight.
- 📱 **Modern Responsive UI:** Polished dark/light dashboard layouts powered by Tailwind CSS and interactive charts.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Component Architecture:** Modular React Components & Custom Hooks
- **Icons:** Lucide React

---

## 🚀 Getting Started

```bash
git clone https://github.com/hmkborhanuddin2004-tech/employee-productivity-system.git
cd employee-productivity-system/web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
