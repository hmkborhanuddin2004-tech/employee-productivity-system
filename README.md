# Employee Productivity & Performance Analytics System

An enterprise productivity monitoring, workflow tracking, and operational analytics web application built with Next.js, TypeScript, and Tailwind CSS. Provides management teams with activity tracking, automated timesheets, and performance visualization.

---

## Features

- **Real-Time Productivity Dashboard:** High-level metrics showing team output, active hours, focus scores, and project delivery status.
- **Automated Timesheets & Activity Logging:** Categorized task tracking with automated idle detection and project milestone mapping.
- **Bilingual Interface:** Full support for both English and Bengali (বাংলা) localization for local enterprise workplaces.
- **Role-Based Access Control:** Role-based authentication ensuring employee privacy and secure administrative oversight.
- **Responsive Dashboard UI:** Polished dark/light dashboard layouts powered by Tailwind CSS and interactive charts.

---

## Technical Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, PostCSS
- **Component Architecture:** Modular React Components & Custom Hooks
- **Icons:** Lucide React

---

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hmkborhanuddin2004-tech/employee-productivity-system.git
cd employee-productivity-system/web
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
